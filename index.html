📖 Easy Paint Pad 2.1 사용설명서
Easy Paint Pad 2.1은 그림 편집과 악보 보조 작업을 위한 브라우저 기반 편집기입니다.
이미지·텍스트·도형·오선을 객체로 배치하고, 레이어별로 관리한 뒤 EPP 프로젝트나 이미지/PDF로 저장할 수 있습니다.

🗂 1. 파일 · 캔버스

새 파일빈 캔버스로 새 작업 시작Ctrl+N
열기이미지 또는 EPP 프로젝트 열기Ctrl+O
저장현재 작업을 EPP 프로젝트로 저장Ctrl+S
다른 이름으로 저장PNG·JPEG·WebP 등 형식을 선택하여 저장. 모바일에서는 시스템 공유/파일 저장 창을 사용Ctrl+Shift+S
EPP 저장객체·레이어·스타일을 유지하는 편집용 프로젝트 저장Ctrl+E
PDF 저장 / 인쇄A4 PDF 저장 또는 브라우저 인쇄Ctrl+P
캔버스 크기파일 탭의 너비·높이를 지정하고 [적용]
문서화사진·스캔 이미지의 음영을 줄여 문서처럼 보정

📐 3. 도형 · 오선 · 마디줄

직선자유 각도 또는 수평·수직·45°·135°·Shift 고정으로 그리기
사각형 / 타원테두리 두께, 전경색, 채우기(없음·전경·배경)를 적용
화살표직선과 같은 각도 옵션으로 화살표 그리기
오선드래그한 방향을 기준으로 5개의 평행한 오선 생성
마디줄직선 또는 오선 도구를 선택하면 표시됩니다. 체크하면 길이의 1/4·2/4·3/4·끝점에 진행 방향과 직각인 4개의 선을 자동 생성합니다.
오선의 마디줄은 오선 전체 높이를 가로지르고, 직선의 마디줄은 선과 직각인 짧은 표시선으로 생성됩니다.

🎼 4. 도형

도형 도구높은음자리표·낮은음자리표·가온음자리표, 조표, 온쉼표·2분쉼표·4분쉼표·8분쉼표·16분쉼표, 온음표·2분음표·4분음표·8분음표·16분음표, 반복기호, 세로줄, 붙임줄 위·아래, Shuffle 표현기호 1·2 등을 삽입M
크기삽입 시 현재 텍스트 크기를 기준으로 생성되고, 이후 객체 핸들로 다시 조절 가능

🔤 5. 텍스트

텍스트 입력텍스트 도구 선택 후 캔버스를 클릭하여 입력T
글꼴 / 크기한글·영문·음악 글꼴과 글자 크기 설정
스타일굵게·기울임·밑줄 적용
줄간격여러 줄 텍스트의 줄 간격을 70%~300% 범위에서 조절. 기존 텍스트를 선택한 뒤에도 변경 가능
박스 텍스트텍스트 주위에 박스 표시. 패딩·모서리 반경 조절 가능
다시 편집기존 텍스트를 더블클릭하여 내용 수정

🧲 6. 객체 선택 · 이동 · 크기 조절

  • 객체 선택 도구에서 객체를 클릭하면 선택 테두리와 파란 크기 조절 핸들이 표시됩니다.
  • 파란 핸들을 드래그하면 객체 크기를 조절할 수 있습니다. 모바일에서도 손가락으로 핸들을 직접 드래그할 수 있습니다.
  • 여러 객체를 선택한 상태에서 드래그하면 함께 이동합니다.
  • 선택 객체는 방향키로 1px 이동, Shift+방향키로 10px 이동합니다. 다중 선택도 함께 이동합니다.
  • 잠긴 객체 또는 잠긴 레이어의 객체는 편집할 수 없습니다.

▱ 7. 레이어 · 객체 목록

  • 오른쪽 레이어 패널의 ＋ 버튼으로 새 레이어를 추가합니다.
  • 레이어 ↑ / ↓ 버튼으로 레이어 순서를 변경합니다.
  • 레이어별로 표시/숨김과 잠금 상태를 설정할 수 있습니다.
  • 레이어를 잠그면 해당 레이어의 객체는 캔버스에서 선택하거나 수정할 수 없습니다.
  • 현재 레이어 아래에는 그 레이어에 속한 객체 목록이 표시됩니다.
  • 선택 객체는 다른 레이어로 이동할 수 있습니다. 잠긴 대상 레이어에는 이동할 수 없습니다.
  • 개별 객체에도 잠금을 설정하여 위치나 크기 변경을 막을 수 있습니다.

🎨 8. 색상 · 두께 · 투명도

  • 전경색은 선·글자·도형의 기본 색, 배경색은 채우기 등에 사용됩니다.
  • 팔레트와 사용자 지정 색상을 사용할 수 있으며 전경/배경 투명도도 별도로 조절합니다.
  • 선·연필·브러시·도형의 두께는 빠른 두께 버튼 또는 ± 컨트롤로 조절합니다.
  • 모바일에서는 전경색/배경색 버튼을 눌러 터치용 색상 선택창을 엽니다.

🔍 9. 보기 · 모바일

  • 보기 탭에서 확대·축소, 100%, 화면 맞추기를 사용할 수 있습니다.
  • 배율 슬라이더로 세밀하게 확대/축소할 수 있습니다.
  • 라이트/다크 테마를 지원합니다.
  • 모바일에서는 리본 영역을 가로로 스크롤하여 숨겨진 도구를 사용할 수 있습니다.

💡 11. 알아두면 좋은 기능

  • 이미지 파일을 캔버스로 드래그하면 객체로 삽입됩니다. Shift+드롭은 새 파일로 엽니다.
  • 외부에서 복사한 이미지는 Ctrl+V로 객체 삽입할 수 있습니다.
  • EPP로 저장하면 레이어·객체·텍스트·스타일 정보를 보존하여 나중에 다시 편집할 수 있습니다.
  • 회색 원형 핸들은 캔버스 크기 조절, 파란 사각형 핸들은 선택 객체 크기 조절입니다.
  • 작업이 복잡할수록 레이어를 나누고 레이어/객체 잠금을 사용하면 실수로 움직이는 것을 줄일 수 있습니다.
