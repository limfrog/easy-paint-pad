# 🎨 Easy Paint Pad

브라우저에서 바로 실행되는 HTML5 Canvas 기반 그림판/이미지 편집기입니다.  
일반 드로잉뿐 아니라 **객체 편집, 캔버스 레이어, 범위 선택, 텍스트, 악보용 도형, 이미지 저장, EPP 프로젝트 저장, PDF 출력, 모바일 터치 조작**을 지원합니다.

> 문서 기준 버전: **v1.6.32**

## 주요 기능

- **캔버스 레이어**
  - 여러 레이어 생성
  - 레이어 표시/숨김
  - 레이어 잠금/해제
  - 레이어 순서 변경
  - 레이어 이름 변경
  - 선택 객체를 다른 레이어로 이동
  - 현재 레이어별 객체 목록 관리
- **객체 편집**
  - 이미지, 획, 도형, 텍스트를 객체 단위로 관리
  - 선택, 이동, 크기 조절, 복제, 삭제
  - 객체 개별 잠금
  - 다중 선택 및 그룹 이동
- **범위 선택**
  - 픽셀 영역 선택
  - 이동, 복사, 잘라내기, 삭제, 붙여넣기
  - 현재 작업 레이어 기준으로 편집
  - 잠긴 레이어는 범위 편집 대상에서 제외
- **그리기**
  - 연필, 브러시, 지우개
  - 선, 사각형, 타원, 화살표
  - 악보용 오선
  - 선 두께 조절
  - 도형 채우기
- **텍스트**
  - 다양한 한글/영문 웹폰트
  - 글자 크기, 굵게, 기울임, 밑줄
  - 박스 텍스트
  - 패딩, 모서리 반경, 테두리, 배경 설정
- **악보/기호 도형**
  - 높은음자리표, 낮은음자리표, 가온음자리표
  - 조표, 세뇨, 코다, 페르마타
  - 쉼표, 음표, 도돌이표, 세로줄 계열
  - 직접 문자 입력 및 중앙 삽입
- **색상**
  - 전경색 / 배경색
  - 기본 팔레트 + 사용자 색상 슬롯
  - 전경/배경 투명도
  - 모바일 전용 색상 선택 UI
- **파일**
  - 이미지 열기
  - EPP 프로젝트 저장/열기
  - PNG / JPEG / WebP 저장
  - A4 PDF 저장
  - 인쇄
  - 최근 작업 파일
- **이미지 처리**
  - 이미지 전체 크기 조절
  - 문서화(음영 제거) 기능
- **보기**
  - 확대/축소
  - 100%
  - 화면 맞추기
  - 라이트 / 다크 테마
  - `Space + 드래그`로 캔버스 위치 이동
- **모바일**
  - 한 손가락 그리기/선택
  - 두 손가락 핀치 확대/축소
  - 레이어 패널 오버레이
  - 모바일 색상 UI
  - 가상 키보드 대응

## 화면 구성

Easy Paint Pad는 상단 리본 방식으로 구성되어 있습니다.

- **파일** — 새 파일, 열기, 저장, PDF, 인쇄, 크기조절, 문서화
- **그리기** — 실행취소/다시실행, 선택, 그리기, 도형, 텍스트, 색상
- **보기** — 확대/축소, 배율, 테마
- **도움말** — 프로그램 정보, 사용설명서, 제작자 연락
- **오른쪽 패널** — 레이어 목록 + 현재 레이어의 객체 목록

모바일에서는 오른쪽 패널이 기본적으로 숨겨지며, 상단의 레이어 버튼으로 열 수 있습니다.

## 레이어 시스템

각 객체는 하나의 레이어에 소속됩니다.

새 객체는 **현재 선택된 레이어**에 생성됩니다.  
레이어 목록은 화면에서 위쪽에 표시된 레이어가 시각적으로 더 위에 그려지도록 관리됩니다.

레이어에서 할 수 있는 작업:

- `＋` 새 레이어 만들기
- `↑ / ↓` 레이어 순서 변경
- `✕` 레이어 삭제
- `◉ / ○` 표시 / 숨김
- `🔓 / 🔒` 잠금 / 해제
- 레이어 이름 더블클릭 → 이름 변경

레이어를 잠그면 해당 레이어의 객체는 캔버스에서 선택하거나 수정할 수 없습니다.  
레이어를 숨기면 그 레이어의 모든 객체가 화면과 선택 대상에서 제외됩니다.

선택한 객체는 객체 목록 위의 **이동할 레이어** 메뉴를 이용해 다른 레이어로 옮길 수 있습니다.

## 파일 형식

| 형식 | 용도 |
|---|---|
| `.epp` | Easy Paint Pad 프로젝트. 객체와 레이어 정보를 유지하여 다시 편집 가능 |
| `.png` | 무손실 이미지 |
| `.jpg` / `.jpeg` | 사진 중심 이미지, 품질 조절 가능 |
| `.webp` | 웹용 고압축 이미지, 품질 조절 가능 |
| `.pdf` | A4 세로 PDF 출력 |

이미지 형식으로 저장하면 화면에 보이는 레이어들이 하나의 이미지로 합쳐집니다.  
나중에 계속 편집해야 하는 작업은 `.epp` 형식으로 저장하는 것이 좋습니다.

## 실행 방법

별도의 빌드 과정은 필요하지 않습니다.

1. 저장소 파일을 웹 서버 또는 GitHub Pages에 배포합니다.
2. `index.html`을 브라우저에서 엽니다.
3. PWA 설치를 지원하는 브라우저에서는 설치형 앱처럼 사용할 수도 있습니다.

로컬 파일(`file://`)로 직접 여는 것보다 HTTP/HTTPS 환경에서 실행하는 것을 권장합니다. 서비스워커, PWA, 파일 접근 기능은 브라우저 보안 정책상 웹 서버 환경에서 더 안정적으로 동작합니다.

## 브라우저 참고사항

- 기본 편집 기능은 최신 Chromium, Safari, Firefox 계열에서 사용할 수 있습니다.
- **최근 파일** 기능은 File System Access API가 필요한 기능이므로 지원 브라우저에서만 활성화됩니다. 현재 앱 UI에서는 Chrome/Edge 사용을 안내합니다.
- PDF 저장은 필요할 때 jsPDF를 CDN에서 불러오므로 인터넷 연결이 필요할 수 있습니다.
- 일부 웹폰트와 음악 기호 폰트는 Google Fonts를 사용합니다.

## PWA / 업데이트 구조

주요 파일:

```text
easy-paint-pad/
├── index.html
├── sw.js
├── manifest.json
├── icon-192.png
├── icon-512.png
├── README.md
└── GUIDE.md
```

일반적인 프로그램 버전 업데이트에서는 다음 두 파일만 교체하도록 관리합니다.

```text
index.html
sw.js
```

`manifest.json`은 앱 이름, 아이콘, 시작 경로 등 PWA 메타데이터가 실제로 변경될 때만 수정합니다.

서비스워커는 새 캐시 버전을 설치한 뒤 업데이트 배너를 표시하고, 사용자가 업데이트를 적용하면 새 버전으로 전환합니다.

## 프로젝트 저장 데이터

EPP 파일에는 다음과 같은 편집 정보가 저장됩니다.

- 캔버스 크기
- 객체 정보
- 이미지 데이터
- 객체별 스타일
- 객체별 `layerId`
- 레이어 목록
- 레이어 표시/잠금 상태
- 현재 활성 레이어
- 프로젝트 메타데이터

이 때문에 EPP 파일은 PNG/JPEG 같은 완성 이미지와 달리 다시 열어서 편집할 수 있습니다.
